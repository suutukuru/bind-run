## 2026-10-19 iPhone で灰色しか出ない件の調査

- 報告: 公開版を iPhone で開くと、濃い灰色（ほぼ黒）の画面しか見えない（BUG-006）。
- 追加（CI）: 実ブラウザのテスト（Chrome を必須、WebKit を参考）。画面の画素、タッチのドラッグ、ブラウザのコンソール出力を CI のログで読めるようにした。
- 結果: Chrome・WebKit ともゲームは描画される。原因は未特定。有力な仮説は iPhone の古いキャッシュと iPhone 固有の WebGL。
- 対処: 公開 URL ごとに `index.pck?v=<コミット>` で取得させる（キャッシュ対策）。`?debug` で画面下にログと WebGL 情報を出す診断モードを追加（`ci/export_presets.web.cfg` の `html/head_include`）。
- 訂正: 一時「WebKit で iPhone と同じ症状を再現できた」と報告したが、WebKit でも描画できていたため撤回した（WebGL エラーは出るが描画は止まっていなかった）。
- 結果（2026-10-19）: オーナーの iPhone で、新しいタブで `?debug` 付きの URL を開くと動いた（BUG-006 は Fixed。原因は古いキャッシュの可能性が高い）。タイトル・レベルアップ・ポーズまで確認。
- 新たに分かったこと: 70 体を倒して LV 3（経験値オーブを拾えていない、R-18）。FPS 30（低電力モードの可能性、R-19）。

## 2026-10-19 マス目・紐を長く・視界を広く

- オーナー指示: 移動が分かるようにマス目を付ける。紐を少し長くする。フィールドを少し広く映す。
- 追加: `GridBackground`（床のマス目。1 マス 100px、5 マスごとに太線。カメラの映る範囲だけ描く）。
- 変更（既定値）: 紐の最大長 `max_radius` 160 → 240、たるみ `natural_radius` 100 → 180。視界 `view_short_side` 600 → 900（game-design 3.4 の提案値）。TUNE の上限も拡大し、「View size」スライダーを追加。
- 影響（要確認）: 視界が広がるぶん、キャラ・敵は画面上で小さく見え、敵の出現位置（画面の外側）も遠くなる。敵との接触が遅くなる可能性がある。体感はオーナーの実機で確認する。
- CI で発覚: たるみを 150 にすると、全力で離れても伸び率が約 0.81 で止まり、紐攻撃（しきい値 0.9）が発動しなくなった（弾性の釣り合い: 速度 220 ÷ 弾性 3 ≒ 73px。たるみから最大長までの幅 60px なら 1.0、90px なら 0.81）。幅を従来の 60px に保つため、たるみは 180 にした。

## 2026-10-19 移動速度・紐・視界をさらに調整

- オーナー指示: 移動速度を上げる／紐を 2 倍くらい長く／カメラを 1.5 倍くらい広く。
- 変更（既定値）: 移動速度 220 → 320。紐の最大長 240 → 480、たるみ 180 → 380。視界 900 → 1350。TUNE の上限も拡大。
- 設計メモ: 紐攻撃（しきい値 0.9）が全力で離れて届く条件は「速度 ÷ 弾性 ≧ 0.9 ×（最大長 − たるみ）」。速度 320 ÷ 弾性 3 ≒ 107px なので、幅を 100px（480 − 380）にした。速度や弾性を変えるときはこの関係に注意する。
- 日本語化（オーナー承認: IPAゴシックを同梱）: ゲーム内の文言を日本語にした。`assets/fonts/ui_font.ttf` は IPAゴシックから使う文字だけを切り出した派生フォント（約 89KB、名前は BindRunUI に変更、`tools/subset_font.py` で生成）。ライセンス全文は `assets/fonts/LICENSE-IPA.txt`。`project.godot` の `gui/theme/custom_font` で全 UI に適用。ADR-013（英語のみ）を置き換え、R-12 を解消。TUNE ボタンは「調整」に変更。デバッグ表示（F3 / ?debug のログ）は英語のまま。
- 強化「長い紐」は +20 → +40（紐が 2 倍になったため）。
