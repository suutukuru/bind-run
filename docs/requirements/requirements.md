# 要件定義書（初版）

- 版: 0.1（Phase 0）
- 作成日: 2026-10-19
- 仕様の分類: **[確定]** オーナーが明示的に決めた内容 / **[提案]** Claude の推奨 / **[仮決定]** 開発を進めるため一時採用 / **[未決定]** / **[要検証]** 動かさないと判断できない

---

## 1. 背景と目的

- Web アプリ開発経験のあるオーナーが、ゲーム開発（ゲームループ、物理、ゲーム特有の設計）を学びながら、スマートフォン向け 2D ゲームを完成させる。
- 成果物は「遊べるゲーム」と「判断の記録（ドキュメント）」の両方。

## 2. ゲームのコンセプト

**「ゴム紐でつながった 2 人が、引っ張り合いながら敵の群れを切り抜けるサバイバル」**

- ジャンル: 2D サバイバルアクション型ローグライト **[確定]**
- 参考構造: 敵の群れ → 撃破 → 経験値 → レベルアップで強化を選択 → 一定時間生存 **[確定]**
- 独自性: 2 人のキャラクターが共通の接続点（ハブ）を介したゴム紐で接続されている。紐は「移動の制約」であると同時に「攻撃手段」でもある **[確定]**

## 3. 想定するプレイヤー

- スマートフォンで短時間（1 プレイ 5〜15 分程度）遊ぶライトゲーマー〜中級者 **[提案]**
- 2 キャラ同時操作という独特の操作に挑戦したいプレイヤー

## 4. 基本的な遊び方

1. 左右の操作で A と B を別々に動かす。
2. 敵は自動で近づいてくる。各キャラは武器で自動攻撃する。
3. 2 人を離すと紐がピンと張り、張った紐に触れた敵にダメージ（**[要検証]**）。
4. 敵を倒して経験値を集め、レベルアップ時に 3 つの強化から 1 つ選ぶ（候補数は **[仮決定]**）。
5. 制限時間まで生き残ればクリア。HP が 0 になればゲームオーバー。

## 5. ゲームの特徴

| 特徴 | 内容 | 分類 |
|---|---|---|
| 2 キャラ独立操作 | 1 人のプレイヤーが A・B を同時に操作 | 確定 |
| ゴム紐による接続 | 共通の接続点（ハブ）から各キャラへ紐が伸びる | 確定 |
| 紐の最大長 | 伸びきると離れる方向の移動が制限される | 確定 |
| 紐の弾性 | 反発・伸縮の表現 | 確定（強さ・方式は要検証） |
| 紐攻撃 | 張った紐に触れた敵にダメージ。武器とは別系統 | 「検討する」= 要検証 |
| 自動攻撃武器 | キャラごとに異なる武器 | 確定 |

## 6. 機能要件

ID の帯: 00x=キャラ/紐、01x=敵、02x=武器、03x=紐攻撃、04x=成長、05x=進行、06x=入力、07x=UI

### 6.1 キャラクターとゴム紐

| ID | 要件 | 分類 | 想定フェーズ |
|---|---|---|---|
| FR-001 | プレイヤーはキャラクター A を 8 方向以上（アナログ可）に移動できる | 確定 | 1 |

## 8. 操作要件

- 2 キャラを **同時に・独立して** 動かせること（確定）。
- 移動速度はアナログ入力の強さに比例してよい（提案）。
- 紐が伸びきったときに「止められた」ことが見た目でわかる（張り表現）こと（提案）。
- **[要検証]** 片手 1 キャラの操作負担が許容範囲か。許容できない場合の代替案（片方を自動追従させる等）は risks.md の R-02 を参照。

## 10. 制約事項

- エンジンは Godot 4 系（2026-10-19 時点の最新安定版は 4.7.2）、言語は GDScript **[確定]**
- iOS ビルドには macOS 環境が必要。現時点で Mac の有無は不明 **[未決定]**
- Claude Code の作業環境（クラウドのコンテナ）からは Godot を取得・実行できない（ネットワーク制限）。実行確認はオーナーの Windows 環境で行う **[確定：環境調査結果]**
- 初期版はシングルプレイのみ **[確定]**

## 11. 初期リリースの範囲（v1.0 の候補）

- キャラ 2 人（A・B 固定）、武器 2〜3 種、敵 3〜4 種、強化 10〜15 種、ステージ 1 つ、制限時間クリア **[提案]**

## 12. 将来対応する機能

- 3〜4 人のオンラインマルチプレイ（全員が 1 つのハブにつながる構造を想定）
- キャラクター・武器の追加、ステージ追加、恒久強化（メタ進行）

## 13. 対象外の機能（初期版）

- ネットワーク通信、サーバー、同期処理
- 課金、広告、ランキング
- 障害物に紐が巻き付く表現（紐は常に直線とする **[仮決定]**）

### 15.2 面白さの仮説（プレイテストで評価。完了判定とは別）

| ID | 仮説 | 評価方法の例 |
|---|---|---|
| H-01 | 2 人を離すと「攻撃範囲が広い／紐攻撃が使える」利点と「挟まれやすい・操作が難しい」欠点が生まれ、距離の判断が面白い | 平均距離の記録、プレイ後の感想 |
| H-02 | 張った紐で敵をなぎ払う瞬間に「狙って成功させた」快感がある | 紐撃破数、意図的に狙ったかの自己評価 |
| H-03 | 紐の制限は理不尽ではなく「工夫の材料」と感じられる | 「引っかかって死んだ」と感じた回数 |
| H-04 | 2 キャラ同時操作は練習すれば 5 分以内に慣れる | 初回〜3 回目のプレイの生存時間 |
| H-05 | 敵が多くても 2 人とハブの位置関係を見失わない | 見失った回数の自己申告 |
| H-06 | 強化の選択によって紐の使い方（離す/寄せる）が変わる | 強化別の平均距離 |
