# オーナー確認リスト（スマホで確認してほしい点）

- 作成日: 2026-10-19
- 目的: Claude が自動テスト（CI）で確認できた範囲の外 — **実際の見た目・指の操作・手触り・面白さ** — を、あとからまとめて確認するためのリスト。
- 結果は気づいた順で構いません。「○ / △ / ×」と一言あれば十分です。気になったことはそのまま教えてください。

## 0. 遊び方・開き方

- URL: **https://suutukuru.github.io/bind-run/** （push のたびに自動で更新されます）
- 古い画面が出る場合は、ページを再読み込みするか、Safari のタブを閉じて開き直してください（ブラウザのキャッシュが残ることがあります）。
- 操作: 画面の**左半分**を指でドラッグ → 青いキャラ（A）、**右半分**をドラッグ → 橙のキャラ（B）。指を置いた位置が中心になります（フローティング式）。2 本指で同時に動かせます。
- 画面の左上に小さな文字（FPS・画面サイズ・位置・敵の数）が出ています。**不具合の報告には、この文字を含めたスクリーンショット**があると原因を特定しやすくなります。
- 画面右上の **調整** で紐の調整パネルを開閉できます。左上の **II** でポーズします。
- 表示は日本語です（IPAゴシックを同梱。字が四角（□）になる所があれば教えてください）。

## 1. まず確認したいこと（iPhone で濃い灰色しか出ない件・BUG-006）

**いまいちばん知りたいこと**: 次の手順で iPhone の表示を教えてください。

1. Safari の**今のタブを閉じる**。
2. **新しいタブで** https://suutukuru.github.io/bind-run/?debug を開く（末尾の `?debug` が目印）。
3. 画面の下に出る**緑色のログのスクリーンショット**を送る（`webgl2:` の行と `MenuPanel 'BIND RUN'` の行が手がかり）。
4. タイトル画面（BIND RUN と START）が出ているかも教えてください。

| 見えたもの | 意味 |
|---|---|
| タイトル画面が普通に出た | 古いキャッシュが原因でした（直っています）|
| 暗いまま・緑のログに `MenuPanel` の行あり | 新しい版は動いているが、描画だけ失敗。iPhone 固有の描画の問題 |
| 暗いまま・`MenuPanel` の行なし | ゲームが起動していない。ログのエラーで原因を探します |
| 緑のログ自体が出ない | 古い `index.html` が使われている。設定アプリ → Safari →「履歴とWebサイトデータを消去」を試してください |

## 3. 紐の手触り（Phase 2）— いちばん大事

調整パネルで値を変えながら試してください。**「どの設定がいちばん気持ちいいか」**が知りたいことです。

| # | 試すこと | 見るポイント | 感想 |
|---|---|---|---|
| 3-1 | 2 人を離していく | 紐が白 → 黄 → 赤と変わり、限界で止まる。**限界が理不尽に感じないか**（H-03） | |
| 3-2 | `Limit: drag partner` ⇄ `Limit: block` を切り替える | drag=押した側が止まり相方が引きずられる／block=押した側が止まるだけ。**どちらが操作しやすいか**（U-02） | |
| 3-3 | `Elastic pull` を 0 / 3 / 8 に変える | 0=硬い壁／大きいほど「ゴムに引き戻される」感じ。**ゴムらしさと操作のしにくさのバランス** | |
| 3-4 | `Slack length`（たるみの長さ）を変える | たるみが長いと、自由に動ける範囲が広がる | |
| 3-5 | `Hub inertia` を 0 / 5 / 15 に変える | 0=ハブは常に 2 人の中点で、紐は一直線／大きくすると**ハブが遅れてついてきて紐がしなる**（ADR-002 案 B）。面白いか、操作が難しくなるか | |
| 3-6 | 「紐の最大長」を変える | 画面に対して長すぎ/短すぎないか（U-01 の向きにも関係） | |
| 3-7 | `Show hub dot` のオン/オフ | 点が消えても動きは変わらない（FR-008） | |

→ 決めてほしいこと（結果を踏まえて `architecture-decisions.md` に採用案を記録します）:
- **限界時の方式**: drag / block
- **弾性の強さ・たるみの長さ・最大長の初期値**
- **ハブに慣性を持たせるか**

## 10. 既知の制約・注意

- **Claude はゲームを画面で見ていません。** CI（ヘッドレス）で、スクリプトの読み込み・単体テスト・ゲームの通しプレイ（ボットが 25 秒のランを勝利まで、敵に囲まれてゲームオーバーまで）を自動確認していますが、**描画の見た目・指の操作・手触り・面白さ**は未確認です。
- 音は一切ありません。
- カメラはハブ（2 人の中点付近）に固定で追従します。ステージの壁はなく、フィールドは無限です。
- 60Hz 以外の画面（120Hz の ProMotion など）で、物理 60Hz との差によるカクつきが出る可能性があります（物理補間は未導入）。出たら教えてください。
- Web 版は初回の読み込みに時間がかかります（約 10MB）。
